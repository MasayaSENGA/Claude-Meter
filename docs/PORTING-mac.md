# Mac 版への移植 引き継ぎ資料

Windows 版 Claude Meter（`src/ClaudeMeter.cs`）と同じ機能を macOS で作るための仕様メモです。
Windows 版のコードを読まなくても作れるよう、API の形式・判定ロジック・描画寸法・定数をまとめています。
迷ったら Windows 版のコードを正とします。

## 1. 方針

- **言語・UI:** Swift + SwiftUI（必要に応じて AppKit）。Windows 版のコードは WinForms 専用なので流用せず、作り直す。
- **置き場所:** このリポジトリの `mac/` フォルダ。README と LICENSE は共有する。
- **管理者権限:** 不要にする（ビルドは Xcode か Command Line Tools、配置はユーザーのフォルダ）。
- **表示方法:** 常に手前に浮かぶ小さなウィンドウ（Windows 版と同じ）を基本にする。`NSPanel` を `.floating` レベル・タイトルバーなし・`isMovableByWindowBackground` で作る。メニューバー常駐（`NSStatusItem` か `MenuBarExtra`）は Windows 版のタスクトレイの代わりとして併用する。
- **Retina:** macOS がポイント単位で自動処理するので、Windows 版の DPI 対応（`Dpi` クラス、`S()` による拡大、`WM_DPICHANGED`）は移植不要。以下の寸法はすべて「ポイント」として読めばよい。

## 2. 使用状況の取得

### 2.1 エンドポイント

```
GET https://api.anthropic.com/api/oauth/usage
Authorization: Bearer <accessToken>
anthropic-beta: oauth-2025-04-20
Accept: application/json
User-Agent: ClaudeMeter/1.0
```

タイムアウトは 15 秒。Claude Code の `/usage` と同じ非公開エンドポイントなので、仕様が変わる可能性がある。

### 2.2 応答（使う部分だけ）

```json
{
  "five_hour": { "utilization": 24.0, "resets_at": "2026-10-22T03:00:00.844526+00:00" },
  "seven_day": { "utilization": 5.0, "resets_at": "2026-10-28T22:00:00.844550+00:00" },
  "limits": [
    { "kind": "session", "percent": 24, "resets_at": "...", "scope": null },
    { "kind": "weekly_all", "percent": 5, "resets_at": "...", "scope": null },
    { "kind": "weekly_scoped", "percent": 0, "resets_at": "2026-10-28T22:00:00+00:00",
      "scope": { "model": { "id": null, "display_name": "Fable" }, "surface": null } }
  ]
}
```

| 表示 | 取り出し方 |
|---|---|
| 5時間制限 | `five_hour.utilization`（0〜100 の割合）と `five_hour.resets_at` |
| 週間制限 | `seven_day.utilization` と `seven_day.resets_at` |
| 週間制限（Fable） | `limits[]` のうち `scope.model.display_name` に "fable" を含む（大文字小文字は区別しない）最初の要素の `percent` と `resets_at`。見つからなければ、念のためトップレベルのキー名に "fable" を含むオブジェクト（例 `seven_day_fable`）の `utilization` を探す |

- `utilization` / `percent` が無いか `null` のときは「データなし」扱い。
- `resets_at` は ISO 8601 文字列が基本。数値（UNIX 秒）で来る場合も受け付ける。`null` なら「未使用」と表示する。
- 他にも多数のキー（`seven_day_opus`、`extra_usage` など）が来るが無視してよい。

### 2.3 ログイン情報（macOS で一番の違い）

- Windows / Linux の Claude Code は `~/.claude/.credentials.json`（環境変数 `CLAUDE_CONFIG_DIR` があればそのフォルダ）に保存する。
- **macOS の Claude Code はキーチェーンに保存する。** 汎用パスワード項目で、サービス名は `Claude Code-credentials` のはず（**要確認**: `security find-generic-password -s "Claude Code-credentials"` で項目があるか確かめる。値は表示しないこと）。中身は下と同じ JSON 文字列と想定している。
- キーチェーンに無ければ `~/.claude/.credentials.json` も見る。
- 初回のキーチェーン読み取りでは、許可を求めるダイアログが出る。

```json
{
  "claudeAiOauth": {
    "accessToken": "...",
    "refreshToken": "...",
    "expiresAt": 1792000000000,
    "refreshTokenExpiresAt": 1799000000000,
    "scopes": ["user:inference", "user:profile", "..."],
    "subscriptionType": "team",
    "rateLimitTier": "..."
  }
}
```

`expiresAt` と `refreshTokenExpiresAt` は UNIX ミリ秒。

### 2.4 トークンの更新

取得のたびにログイン情報を読み直し、`expiresAt` が「今 + 60 秒」より前なら更新してから使う。
期限内でも usage が 401 を返したら、1 回だけ強制的に更新して再試行する。

```
POST https://platform.claude.com/v1/oauth/token
Content-Type: application/json

{
  "grant_type": "refresh_token",
  "refresh_token": "<refreshToken>",
  "client_id": "9d1c250a-e61b-44d9-88ed-5944d1962f5e",
  "scope": "<scopes をスペース区切りで連結>"
}
```

- `client_id` は Claude Code の公開クライアント ID（秘密情報ではない）。
- 応答の `access_token`、`refresh_token`（無ければ元のまま）、`expires_in`（秒）、`refresh_token_expires_in`（秒、あれば）で次を更新し、**元の保存先（キーチェーンかファイル）に書き戻す**。他のフィールドはそのまま残す。
  - `accessToken` = `access_token`
  - `refreshToken` = `refresh_token`
  - `expiresAt` = 今（ミリ秒）+ `expires_in` × 1000
  - `refreshTokenExpiresAt` = 今（ミリ秒）+ `refresh_token_expires_in` × 1000
- 書き戻すことで Claude Code CLI も新しいトークンをそのまま使える。書き戻さないと、リフレッシュトークンが入れ替わった時点で CLI がログアウト状態になる。
- ファイルに書く場合は一時ファイルに書いてから置き換え、失敗しても一時ファイル（トークン入り）を残さない。
- 更新の要求が 400 / 401 なら、リフレッシュトークン切れとして再ログインを促す。
- トークンは `api.anthropic.com` と `platform.claude.com` 以外に送らない。ログや画面にも出さない。

### 2.5 取得の間隔と失敗時

- 自動取得の間隔は設定値（既定 5 分）。起動直後に 1 回取得する。ダブルクリックとメニューの「今すぐ更新」でも取得する。取得中に重ねて取得しない。
- 失敗したら、前回成功した値を残したまま、エラー文だけ差し替えて表示する。
- 1 分間隔などで頻繁に取得すると 429 になりやすい（実際に起きた）。

| 状況 | 表示する文言 |
|---|---|
| ログイン情報が無い | Claude Code のログイン情報が見つかりません（claude で /login してください） |
| アクセストークンが無い | ログイン情報にアクセストークンがありません（claude で /login してください） |
| 期限切れでリフレッシュトークンも無い | トークンの期限切れ（claude で /login してください） |
| 更新の要求が 400 / 401 | ログインの有効期限切れ（claude で /login してください） |
| 更新の応答に access_token が無い | トークン更新に失敗（claude で /login してください） |
| usage が 401（再試行後も） | 認証エラー（claude で /login してください） |
| usage が 429 | 取得回数の制限中（しばらく待ってください） |
| その他の HTTP エラー | 取得失敗: HTTP <コード> |
| 通信できない | 通信エラー: <理由> |

## 3. ピーク／オフピーク判定

公式の定義とは照合していない既定値なので、設定で変えられるようにする。

- 既定: 基準タイムゾーン `America/Los_Angeles`（Windows 版の ID は `Pacific Standard Time`）、`05:00`〜`11:00`、平日のみ。
- 判定: 時刻を基準タイムゾーンに変換し、「平日のみ」がオンで土日ならオフピーク。そうでなければ `開始 <= 時刻 < 終了` でピーク。開始 > 終了のときは日付をまたぐ（`時刻 >= 開始 || 時刻 < 終了`）。夏時間は自動で考慮される（タイムゾーン変換に任せる）。
- 次に切り替わる時刻: 今の分の次から 1 分刻みで最大 8 日先まで調べ、判定が変わる最初の時刻（ローカル時刻）を表示する。
- 日本時間では、夏時間中は 21:00〜翌3:00、冬時間中は 22:00〜翌4:00 になる。

## 4. 表示仕様

### 4.1 色

| 名前 | RGB | 用途 |
|---|---|---|
| Back | 30, 30, 32 | 背景 |
| 枠線 | 70, 70, 75 | ウィンドウの外枠（1pt） |
| Track | 58, 58, 62 | バー・文字盤の未使用部分 |
| Text | 235, 235, 235 | 見出し・ラベル・針・主目盛り |
| Sub | 150, 150, 155 | 補足文字・副目盛り・データなしの針 |
| Ok | 70, 150, 230 | 使用率 70% 未満（青） |
| Warn | 230, 180, 60 | 使用率 70% 以上 90% 未満（黄）・エラー文 |
| Danger | 225, 80, 80 | 使用率 90% 以上（赤） |
| Peak | 225, 95, 80 | ピークタイム表示 |
| OffPeak | 90, 190, 120 | オフピーク表示 |
| Brand | 217, 119, 87 | アイコンのオレンジ |

### 4.2 文字

Windows 版は Yu Gothic UI / Segoe UI。Mac ではシステムフォント（日本語はヒラギノ）でよい。

| 用途 | 大きさ | 太さ |
|---|---|---|
| title（見出し・ピーク表示） | 12pt | 太字 |
| label（制限の名前） | 12pt | 標準 |
| pct（使用率の数字） | 13.33pt | 太字 |
| small（補足） | 10.67pt | 標準 |

### 4.3 文言の書式

- 使用率: 四捨五入した整数 + `%`。データなしは `—`。
- 日時（FormatWhen）: 今日なら `HH:mm`、それ以外は `M/d(曜) HH:mm`（曜は 日月火水木金土）。
- 残り時間（FormatSpan）: 1 分未満 `まもなく`、1 時間未満 `あと<分>分`、1 日未満 `あと<時>時間<分>分`、それ以上 `あと<日>日<時>時間`。
- 更新状態（右上）: 取得中は `更新中…`、取得後は `HH:mm 更新`。
- 30 秒ごとに再描画して残り時間を進める。

### 4.4 共通レイアウト（座標は左上原点・下向き）

AppKit の `NSView` は左下原点なので、`isFlipped = true` にするか座標を変換すること。

- 左右の余白 `pad` = 12、内側の幅 `w` = ウィンドウ幅 − 24。
- 見出し `Claude Meter`（title, Text）を (12, 8)。右上に更新状態（small, Sub）を右端そろえで y = 10。
- メーター部は y = 34 から始まる。
- メーター部の下にピーク表示:
  - 直径 10 の丸（Peak / OffPeak 色）を (12, y+4)。
  - `ピークタイム` / `オフピーク`（title、同じ色）を (27, y)。
  - `開始 <日時>（<残り>）`（オフピーク時）/ `終了 <日時>（<残り>）`（ピーク時）を small・Sub で、右端そろえで y+2。縦並びのときだけ (27, y+19) に 2 行目として出す。
- エラーがあれば、最下部（y = 高さ − 20、高さ 16）に Warn 色・small で 1 行表示し、はみ出しは「…」で省略する。

### 4.5 バー表示

ウィンドウ: 幅 260、高さ 34 + 46 × 本数 + 50（Fable 表示ありで 222、なしで 176）。各制限は 46 ずつ下へ:

- ラベル（label, Text）を (x, y)。
- 使用率（pct、色は使用率に応じる）を右端そろえで y − 2。
- 高さ 7 の角丸バー（両端が半円）を (x, y+20)、幅 w。未使用部分は Track、使用部分は使用率の色で幅 `max(7, w × 使用率 / 100)`。使用率 0 なら塗らない。
- 補足（small, Sub）を (x, y+29): データなしは `データなし`、リセット時刻があれば `リセット <日時>（<残り>）`、無ければ `未使用`。

### 4.6 スピードメーター表示

ウィンドウ:

- 横並び: 幅 24 + 130 × 本数（414 か 284）、高さ 214。セル幅は w ÷ 本数。
- 縦並び: 幅 170、高さ 34 + 134 × 本数 + 56（492 か 358）。セル幅は w、各メーターは 134 ずつ下へ。

1 個の文字盤（セル左上 (x, y)、セル幅 cw）:

- 半径 r = 44、中心 (cx, cy) = (x + cw/2, y + r + 4)。
- 角度は「3 時方向が 0°、時計回りが正」（下向き座標）。文字盤は 150° から 240° 分（左下が 0%、真上が 50%、右下が 100%）。使用率 p の角度は `150 + 240 × p / 100`。
- 注意域の帯: 半径 r + 4、線幅 2。70〜90% を Warn（不透明度 150/255）、90〜100% を Danger（170/255）。
- 文字盤の弧: 線幅 7、端は平ら。全体を Track、0〜p を使用率の色で重ねる。
- 目盛り: 0〜100% を 10% ごとに 11 本。0・50・100% は主目盛り（半径 r−15 〜 r−6、線幅 2、Text）、それ以外は副目盛り（r−11 〜 r−6、線幅 1、Sub）。
- 針: 中心から長さ r − 13、線幅 2.5、両端は丸。色は Text（データなしは Sub）。
- 中心の丸: 半径 5、使用率の色（データなしは Sub）。
- 文字（すべて中央そろえ）:
  - 使用率（pct、使用率の色）を cy + 12。
  - ラベル（label, Text）を cy + 32。
  - リセット時刻があれば `リセット <日時>` を cy + 50、`<残り>` を cy + 64（small, Sub）。
  - データなしは `データなし`、リセット時刻が無ければ `未使用` を cy + 50。
- 使用率は 0〜100 に丸めてから描く。

### 4.7 スイープ（スピードメーター表示の起動演出）

- 起動直後（取得を待たずに開始）と、設定でバーからスピードメーターに切り替えたときに 1 回動かす。設定でオフにできる。
- 0〜0.7 秒で 0% → 100%、0.7〜0.9 秒は 100% で止め、0.9〜1.7 秒で 100% → 実際の値（未取得なら 0%）。
- 動きは easeInOutCubic（`x < 0.5 ? 4x³ : 1 − (−2x + 2)³ / 2`）。
- スイープ中は針・弧・中心の丸・使用率の数字をすべてアニメーション値で描き、色もその値で変える（上がる途中で青 → 黄 → 赤）。データ未取得でも文字盤を点灯させる。
- 描画は 60fps 程度（Windows 版は 15ms 間隔）。`TimelineView` か `CADisplayLink` 相当を使う。

## 5. ウィンドウの振る舞い

- 枠なしの小窓。ドラッグで移動でき、位置を保存する（次回はその位置）。保存位置が画面外なら、メイン画面の右下（余白 16）に出す。
- 「常に手前に表示」の設定に従ってウィンドウレベルを切り替える。
- 不透明度（30〜100%、既定 95%）をウィンドウ全体に適用する。
- ダブルクリックで今すぐ更新。
- 表示形式や Fable の表示を変えてウィンドウの大きさが変わったら、画面からはみ出さないよう位置を戻す。
- Dock に出さない（`LSUIElement = YES`）。Windows 版でもタスクバーと Alt+Tab に出さない作り。
- 二重起動しない。

## 6. メニュー

右クリックとメニューバーのアイコンで同じ内容を出す。

1. 今すぐ更新
2. 常に手前に表示（チェック付き）
3. ログイン時に開始（チェック付き。Windows 版では「Windows 起動時に開始」）
4. 表示／非表示
5. 設定...
6. （区切り線）
7. 終了

- メニューバーのアイコンにカーソルを当てたときの表示（Windows 版のトレイのツールチップ相当）: `Claude 5h:24% 週:5% Fable:0%`（Fable 非表示なら Fable 部分を省く）。
- Windows 版ではトレイアイコンの左クリックで表示／非表示を切り替える。

## 7. 設定

設定画面で編集し、OK を押すとすぐに反映する（再起動不要）。キャンセルで破棄する。「既定に戻す」ボタンも付ける。
保存先は `~/Library/Application Support/ClaudeMeter/settings.json`（または `UserDefaults`）。Windows 版のキー名に合わせておくと分かりやすい。

| キー | 型 | 既定値 | 設定画面の項目 |
|---|---|---|---|
| refreshMinutes | 整数 1〜60 | 5 | 更新間隔（分ごと） |
| peakTimeZone | 文字列 | America/Los_Angeles | 基準タイムゾーン（一覧から選ぶ） |
| peakStart / peakEnd | "HH:mm" | "05:00" / "11:00" | 時間帯 |
| peakWeekdaysOnly | 真偽 | true | 平日のみ（土日はオフピーク） |
| style | "bar" / "gauge" | "bar" | 表示形式（バー／スピードメーター） |
| gaugeVertical | 真偽 | false | メーターの並び（横並び／縦並び）※スピードメーターのときだけ選べる |
| gaugeSweep | 真偽 | true | 起動時に針を最大まで振り切る（スイープ）※スピードメーターのときだけ選べる |
| showFable | 真偽 | true | 週間制限（Fable）を表示 |
| topMost | 真偽 | true | 常に手前に表示 |
| opacity | 小数 0.3〜1.0 | 0.95 | 不透明度（スライダー、% 表示） |
| x / y | 整数 | -1（未保存） | ウィンドウ位置（画面には出さない） |

- 「ログイン時に開始」は設定ファイルではなく OS 側の登録状態で管理する。設定画面にも同じ項目を置く。
- 時間帯の下に、選んだ時間帯をこの Mac の時刻に換算して表示する（例 `この Mac の時刻では 21:00〜翌03:00（基準タイムゾーンの平日のみ）`、平日のみオフなら `（毎日）`）。

## 8. ログイン時に開始

- macOS 13 以降は `SMAppService.mainApp.register()` / `unregister()`。管理者権限は不要。
- それより古い OS も対象にするなら `~/Library/LaunchAgents` に plist を置く。

## 9. アイコン

- 絵柄: Brand 色の円（32 を基準に (1,1)〜(31,31)）に、白い線（太さ 4、端は丸）で次の 2 つを描く。
  - 弧: (8,8)〜(24,24) の円の 135° から 270° 分（下向き座標）
  - 針: 中心 (16,16) から (22,11) への線
- アプリアイコンは `.icns`（`iconutil` で作る）。メニューバー用はテンプレート画像（単色）にすると、ライト／ダークに自然になじむ。

## 10. 配布と注意

- 署名していないアプリは Gatekeeper に止められる。自分で使う分には右クリック →「開く」で起動できる。人に配るなら Developer ID の署名と公証（notarization）が必要。
- README の「注意」節（非公式ツールであること、非公開 API を使っていること、トークンの送信先など）と同じ内容を Mac 版にも書く。
- Claude Code と同時にトークンを更新すると、どちらかで再ログインが必要になる場合がある。更新は期限切れのときだけにする。

## 11. 動作確認

Windows 版には、確認用に描画を PNG に保存して終了するオプションがある（`--snapshot <パス> [倍率] [形式]` と `--snapshot-settings <パス> [x y]`）。Mac 版でも同じような仕組みを作っておくと、画面を目で見なくても見た目を確かめられる。

確認したい組み合わせ:

- バー／スピードメーター（横並び・縦並び）× Fable 表示あり・なし
- データ未取得、取得失敗（エラー行）、429
- ピーク中とオフピーク
- スイープ中のコマ（0.25 秒・1.0 秒・1.5 秒あたり）
- ライト／ダーク外観（メーター自体は常にダークの配色でよい）
